The FM-1 runs other firmware:

It is the same route as Workbench's "Force flash", through M-VAVE's update loader. The voices, projects and settings of the old firmware are not kept.

If the old firmware does not speak the USB-MIDI update protocol, nothing is written and the page says so. To go back to the original firmware later, use Workbench ("Restore original V15").

Do not unplug the cable, and keep the FM-1 powered until the page says it is done. Close other programs and tabs that use the FM-1's MIDI port (Workbench, DAW, MIDIberry).

Leaving FM1-SF2

Puts M-VAVE's original firmware V15 back on the FM-1, the same package the page uses on the way from other firmware, and then writes V15's 128 factory voices (four banks) again, which the original firmware needs. The SF2 bank in the sample flash is not used by V15. The progress shows under Steps above. To come back later, use this page again.

    If something goes wrong
    
    
      
  • The firmware is written by M-VAVE's own update loader, the same route Workbench uses. If it is interrupted, plug in again and run the page once more; it continues from where the FM-1 is.
    • 
      
  • If the FM-1 runs the original firmware or another firmware, the page shows what it runs and asks before it replaces it. If that does not work, install the SF2 firmware with Workbench (Recovery & force update > Force flash) the first time.
    • 
      
  • From other firmware than M-VAVE's original, the page goes through the original firmware V15 first (M-VAVE's own package from fm1_open, Apache-2.0): some firmware, such as Felucca, brings an update loader that takes only packages of the original layout. Stopped in between, the FM-1 stays in that loader or on V15; run the page again.
    • 
      
  • If the FM-1 plays a bank that makes it restart or freeze: hold OCT− and OCT+ while you switch it on, until the screen shows SAFE MODE. It then starts without the bank, and this page can install firmware and a new bank. (It cannot help when the firmware itself does not start: then the FM-1 shows no USB device at all.)
    • 
      
  • The bank lives in the sample flash and stays there when the firmware is updated. It only needs to be sent when it has changed.
    • 
      
  • During the bank transfer the FM-1 shows UPLOAD n Rx; R0 is good, R3 is a flash error.
