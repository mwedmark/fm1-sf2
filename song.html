FM-1

The song stays in the FM-1's RAM until it is switched off or another song is sent. PLAY on the FM-1 starts it from the beginning and stops it; the program page shows where it is. It plays through the same path as MIDI in, so the channels page, mute and solo work as usual. The FM-1 needs the SF2 player firmware with the MIDI file player.
